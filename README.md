# フラッシュ検査

iPhoneの縦画面を想定した検査基準値の暗記ゲーム。静的HTML/CSS/JavaScriptのみ。外部ライブラリ、外部フォント、通信、ログインは不要です。

## 試す

`index.html`をブラウザで開くか、Node.jsでローカルサーバーを起動します。

```sh
node tools/serve.cjs
```

ブラウザで `http://127.0.0.1:4174` を開きます。これは同じPC用のURLです。iPhoneから試す場合はGitHub Pages等へ配置してください。

## モード

- **CHECK**：Low／Normal／High。前・現在・次のカードが縦に並び、正解すると上へ移動。
- **INPUT**：下限4択・上限4択を縦2列で表示し、下限→上限の順に回答。同じラウンドで解き終えた項目は、再出題時にテンキー入力へ移行。片側基準の項目はその側の4択のみ。
- **PICK**：症例ごとの所見一覧から異常値をタップして回収。全項目なら性別を統一した47所見。所見一覧だけをスクロールし、全回収で次の症例へ自動遷移。これは独立生成した検査値を集めた練習用の一覧で、特定疾患の病態を再現する症例ではありません。

モードボタンから直接開始。3・2・1を合計1.5秒で表示し、その後120秒の計測を開始。全モード最大120秒。30秒ごとに段階が上がり、一問の回答期限が短くなります。SOLOは誤答・時間切れで−2秒。CPU戦はCHECKのみ。共通の問題で先に正解した側だけに得点し、即座に次の問題へ進みます。1回のお手付きでその問題の回答権を失い、相手は残り時間内に回答できます。両者お手付き・時間切れは流し。お手付きでコンボが切れ、残り時間や得点の追加減算はありません。CPUはレートによって回答速度と正答率が変わるシミュレーションです。CPUを選択中でもINPUT/PICKはSOLOになります。

正解100点＋速答20点。5コンボごとに倍率が0.5上がり上限3倍。ゲージがたまると12秒間のフィーバー（得点2倍）が自動発動。発動した回答自体は通常倍率、次の回答から2倍です。フィーバー中のミスはコンボを切りますがフィーバーは継続します。

CHECKのSOLOでは誤答にペナルティを加え、選んだボタンだけを無効化して同じ問題を継続します（最大3択）。誤答後は回答期限をリセットします。正解または時間切れで次へ進み、スライド完了は待たずに回答できます（画面遷移直後の130msだけ二重入力を抑制）。初回誤答・正解でカード内に斜線入りの基準範囲を表示し、正解後は今回の値を黄色の矢印で示します。誤答項目は数問後に再出題。終了後に誤答一覧とミス限定の再戦ができます。異常狩りの回答期限切れは一回のミスとして計算し、未回収の異常値をすべて振り返りに記録します。

## 記録と設定

- 正解ごとに10 XP。次レベルに必要なXPは500→675→900→1175…と増加。レベルLでの必要XPは `500 + 150×(L−1) + 25×(L−1)²`。旧版の累計XPを維持し、レベル表示のみ新しい曲線で再計算します。リザルトでXPゲージとレベルアップ音を再生。演出中も再戦・メニューを操作できます。
- CPUレートはCHECKで使用（旧INPUT/PICKレートは記録内に保持）。勝利＋24、敗北・中断−12、引き分け0（範囲400〜5000）。
- 分野限定のCPU戦、基準値を参照したプレイ、ミス限定再戦は練習扱いです。
- 基準値参照・設定・バックグラウンド移動時は一時停止。再開時から時間が動きます。
- 直近200プレイと各条件の上位10件を端末内のlocalStorageに保存。古い最高記録も残します。ランキングは全項目SOLOの完走記録を対象に表示します。
- INPUTの学習履歴・次回復習時刻も端末内に保存。設定からJSONの書き出し／読み込みが可能。旧版のJSONも読み込めます。読み込みは現在の記録を置き換えます。
- BGM／SEの個別ON/OFF・音量、演出控えめに対応。BGM/SEはWeb Audioによる合成音。

ブラウザデータを消すと記録も消えます。プレビューと公開サイト、異なるブラウザ間では記録を共有しません。必要に応じてJSONで移してください。

## INPUTの復習間隔

誤答は12秒後、初回の選択式を一発正解すると30秒後から再出題の対象になります。その間は別の項目を出します。テンキーで一発正解するたびに90秒→5分→30分→6時間→1日→3日→7日→14日→30日→60日へ延長。誤答で短い間隔へ戻します。既習項目の選択式正解では、獲得済みの長い間隔を維持します。男女別の基準は別項目として管理します。

期限を迎えた項目を優先し、次に未学習項目を選びます。対象がすべて復習待ちになればCOMPLETEとして終了。希望時は「追加練習」で待機中の項目も練習できます（ランキング対象外）。「ミスだけ再戦」もその場で再学習できます。選択式からテンキーへの切り替えはラウンド単位、学習間隔はラウンドを越えて保持します。

[Ankiの学習・再学習ステップ](https://docs.ankiweb.net/deck-options.html#learning-steps)を参考にした独自の間隔反復です。FSRSやAnki互換の記憶モデルではなく、個人の忘却曲線を推定するものではありません。

タップ後90ms、問題・入力段階の切り替え後130msだけ入力を抑制。旧問題を押し始めてから自動遷移した場合、そのクリックを新問題へ持ち越しません。キーボードにも同じ制御を適用します。

## 教材データ

`data.js`に提供された基準値を収録（男女別に分けて54エントリ）。空腹時血糖は指定どおり **70〜110 mg/dL**。赤血球・血小板は元の「万」を維持して万/μL、白血球は/μLを表示しています。アルブミン濃度と蛋白分画は別項目。

上下限は正常に含めます。出題値0は生成しません。上下限がある項目は、ユーザー指定の仮定「平均±2SD」に基づき、平均±2.326347874SDより外側（上下各1%）だけを異常問題に採用します。表示精度に丸めてもこの条件を満たすよう、異常側へ切り上げ／切り下げます。片側基準のみの項目はSDを推定せず、基準の12%または表示刻み2個分の大きい方より離れた値を使います。正常値も範囲の内側を中心に出題します。後半の難易度は回答期限・音のテンポで上げ、境界値に近づける方式は使用しません。これは出題のための仮定で、実際の検査値分布を正規分布と断定するものではありません。

「以下」の項目には低値、「以上」の項目には高値の問題を作りません。下限未提示の項目で極端な低値を正常として教えないよう、正常サンプルは提示上限付近から生成しています。基準値はユーザーの教材データであり、各医療機関の最新基準値への置き換えや臨床診断の判定は行っていません。

### 異常方向の出題重み

AST・ALT・総ビリルビンの低値は高値の1/9、赤沈・クレアチニンの低値は高値の1/5、アルブミンの高値は低値の1/5の重みで生成。該当方向も確率ゼロにはしません。他の両側項目は同じ重みです。PICKにも同じ重みを適用します。これらは教材上の優先度で、実際の異常値の発生率・有病率を表した比率ではありません。

方向づけの参考：[AASLD 肝酵素上昇](https://www.aasld.org/liver-fellow-network/core-series/back-basics/how-approach-elevated-liver-enzymes)、MedlinePlusの[赤沈](https://medlineplus.gov/lab-tests/erythrocyte-sedimentation-rate-esr/)、[クレアチニン](https://medlineplus.gov/lab-tests/creatinine-test/)、[アルブミン](https://medlineplus.gov/lab-tests/albumin-blood-test/)。基準値自体は元の教材値を維持します。

## GitHub Pages

公開先： https://valizoj.github.io/dopagaki_study/

`main`ブランチの`/ (root)`をGitHub Pagesの公開元として使用します。ビルド処理は不要です。相対パスなのでリポジトリ名を含むURLでも動きます。`.nojekyll`を同梱しています。

更新時は変更したファイルを`main`へ反映します。GitHub Pagesのデプロイ完了後、同じURLに変更が反映されます。公開URLを変えずに更新する限り、同じブラウザ内の学習記録は引き続き利用できます。
