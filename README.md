# DOPA LAB

iPhoneの縦画面を想定した検査基準値の暗記ゲーム。静的HTML/CSS/JavaScriptのみ。外部ライブラリ、外部フォント、通信、ログインは不要です。

## 試す

`index.html`をブラウザで開くか、Node.jsでローカルサーバーを起動します。

```sh
node tools/serve.cjs
```

ブラウザで `http://127.0.0.1:4174` を開きます。これは同じPC用のURLです。iPhoneから試す場合はGitHub Pages等へ配置してください。

## モード

- **仕分け**：低い／正常／高い。次の問題を予告。
- **穴埋め**：基準範囲の片側を数値入力。専用テンキー、キーボード入力に対応。
- **異常狩り**：4枚から異常値を回収。セットごとに異常1〜3枚、すべて回収すると自動遷移。

全モード120秒。30秒ごとに段階が上がり、一問の回答期限が短くなります。SOLOは誤答・時間切れで−2秒。CPU戦は共通120秒で誤答−150点。CPUはレートによって回答速度と正答率が変わるシミュレーションです。

正解100点＋速答20点。5コンボごとに倍率が0.5上がり上限3倍。ゲージがたまると12秒間のフィーバー（得点2倍）が自動発動。発動した回答自体は通常倍率、次の回答から2倍です。フィーバー中のミスはコンボを切りますがフィーバーは継続します。

正答・誤答の直後から次を回答できます。直前の基準値を画面に残し、誤答項目は数問後に再出題。終了後に誤答一覧とミス限定の再戦ができます。異常狩りの回答期限切れは一回のミスとして計算し、未回収の異常値をすべて振り返りに記録します。

## 記録と設定

- 正解ごとに10 XP。500 XPごとにレベルが上がります。
- CPUレートはモード別。勝利＋24、敗北・中断−12、引き分け0（範囲400〜5000）。
- 分野限定のCPU戦、基準値を参照したプレイ、ミス限定再戦は練習扱いです。
- 基準値参照・設定・バックグラウンド移動時は一時停止。再開時から時間が動きます。
- 直近200プレイと各条件の上位10件を端末内のlocalStorageに保存。古い最高記録も残します。ランキングは全項目SOLOの完走記録を対象に表示します。
- 設定からJSONの書き出し／読み込みが可能。読み込みは現在の記録を置き換えます。
- BGM／SEの個別ON/OFF・音量、演出控えめに対応。BGM/SEはWeb Audioによる合成音。

ブラウザデータを消すと記録も消えます。プレビューと公開サイト、異なるブラウザ間では記録を共有しません。必要に応じてJSONで移してください。

## 教材データ

`data.js`に提供された基準値を収録（男女別に分けて54エントリ）。空腹時血糖は指定どおり **70〜110 mg/dL**。赤血球・血小板は元の「万」を維持して万/μL、白血球は/μLを表示しています。アルブミン濃度と蛋白分画は別項目。

上下限は正常に含めます。「以下」の項目には低値、「以上」の項目には高値の問題を作りません。下限未提示の項目で極端な低値を正常として教えないよう、正常サンプルは提示上限付近から生成しています。基準値はユーザーの教材データであり、各医療機関の最新基準値への置き換えや臨床診断の判定は行っていません。

## GitHub Pages

公開先： https://valizoj.github.io/dopagaki_study/

`main`ブランチの`/ (root)`をGitHub Pagesの公開元として使用します。ビルド処理は不要です。相対パスなのでリポジトリ名を含むURLでも動きます。`.nojekyll`を同梱しています。

更新時は変更したファイルを`main`へ反映します。GitHub Pagesのデプロイ完了後、同じURLに変更が反映されます。公開URLを変えずに更新する限り、同じブラウザ内の学習記録は引き続き利用できます。
